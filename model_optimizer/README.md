# Model Optimizer

`그래도 지켰조?` 프로젝트의 **지식 증류(Knowledge Distillation), 파인튜닝(Fine-tuning), 모델 경량화 실험**을 관리하는 디렉토리입니다. 압연기 시연 환경에서 장갑을 낀 손의 위험 구역 침범과 작업자의 쓰러짐을 탐지하는 모델을 개발하고, Raspberry Pi에서 정확도와 추론 지연시간을 비교합니다.

## 연구 범위

| 과제 | 모델 출력 | 시연에서 검증할 동작 |
| --- | --- | --- |
| 장갑 낀 손 탐지 | 손별 인스턴스 마스크와 신뢰도 | 두 손을 개별 인스턴스로 구분하고, 각 마스크와 미리 정의한 위험 구역(ROI)의 겹침으로 침범을 판정 |
| 쓰러짐 탐지 | 사람별 자세 키포인트와 프레임별 신뢰도 | 연속 프레임의 자세 변화를 사용해 쓰러짐을 판정하고, 쪼그려 앉기나 몸 숙이기에서 오경보가 발생하는지 확인 |

두 과제는 데이터셋, 학습 설정, 평가 결과와 체크포인트를 각각 관리합니다. 공통 설정이나 평가 도구가 필요해지면 두 과제의 입력과 출력 차이를 확인한 뒤 공유합니다.

## 실험 방법

| 방법 | 작업 내용 | 비교 기준 |
| --- | --- | --- |
| 기준 모델 | 사전학습 모델을 고정하고 시연 환경의 검증 영상에서 모델 출력과 실패 사례 기록 | 후속 실험의 초기 성능과 지연시간 |
| 파인튜닝 | 장갑, 조명, 카메라 각도, 작업 동작을 반영한 라벨 데이터로 사전학습 모델을 추가 학습 | 같은 데이터 분할과 평가 조건에서 기준 모델 대비 개선 여부 |
| 지식 증류 | 교사·학생 모델을 선정하고 양쪽이 비교할 수 있는 출력에 증류 손실 적용 | 같은 학생 모델을 같은 라벨 데이터로 학습한 파인튜닝 결과 대비 개선 여부 |
| 의사 라벨링 | 필요 시 SAM 3 등으로 후보 마스크를 만들고 검수 후 학습 데이터에 추가 | 동일한 모델에서 검수한 의사 라벨 추가 전후의 성능 |
| 배포 최적화 | 필요 시 ONNX 내보내기와 양자화를 적용하고, 타깃 런타임에서 출력과 성능 검증 | 변환 전후의 탐지 성능, 지연시간, 메모리 사용량 및 파일 크기 |

장갑 손 모델의 초기 후보는 `YOLO11n-seg`입니다. 쓰러짐 탐지 모델, 교사 모델, 배포 런타임은 데이터와 장치에서 기준 성능을 측정한 뒤 결정합니다.

## 디렉토리 구성안

아래 경로는 구현이 추가되는 순서에 맞춰 생성합니다.

```text
model_optimizer/
├── README.md
├── configs/
│   ├── hand_seg/          # 손 세그멘테이션 학습·평가 설정
│   └── fall_detection/    # 자세 추정·쓰러짐 판정 설정
├── datasets/              # 데이터 버전, 분할 정보와 라벨 규칙
├── scripts/               # 학습·평가·변환 진입점
└── results/               # 지표 요약 및 실패 사례
```

Git에는 코드, 설정, 데이터 버전 정보와 결과 요약을 반영합니다. 원본 영상, 데이터셋, 대용량 체크포인트는 팀이 합의한 저장 위치에서 관리하고 실험 기록에 참조 경로를 남깁니다.

## 시작하기

1. 팀의 원본 데이터와 라벨 버전을 확인합니다. 같은 영상에서 추출한 프레임은 하나의 분할에 함께 두고, 가능하면 촬영 세션을 기준으로 학습·검증·테스트 세트를 나눕니다.
2. 과제별 입력 해상도, 클래스 또는 키포인트 정의, 판정 기준을 정합니다. 위험 구역 좌표는 시연 카메라의 최종 회전 방향과 전처리를 적용한 화면에 맞춥니다.
3. 학습 환경의 Python·프레임워크 버전과 타깃 Raspberry Pi의 OS·추론 런타임을 기록합니다.
4. 기준 모델을 평가한 뒤 파인튜닝을 진행합니다. 증류 실험은 파인튜닝을 마친 학생 모델의 성능을 비교 기준으로 삼습니다.

학습·평가 스크립트가 추가되면 이 절에 설치 명령과 과제별 실행 예시를 추가합니다.

## 평가 및 실험 기록

| 구분 | 기록 항목 |
| --- | --- |
| 손 마스크 및 침범 판정 | 마스크 mAP50–95, 침범 이벤트 재현율, 미탐 및 오경보 사례 |
| 쓰러짐 판정 | 이벤트 단위 정밀도·재현율, 오경보 건수, 쓰러짐 시작부터 감지까지의 시간 |
| 온디바이스 실행 | 전처리·추론·후처리를 포함한 프레임 처리 지연시간 p50·p95, FPS, 최대 메모리 사용량, 모델 파일 크기 |

장치 벤치마크는 동일한 Raspberry Pi, 입력 해상도, 테스트 영상과 워밍업 조건에서 반복합니다. 판정 임계값은 검증 세트에서 정하고, 최종 성능은 분리해 둔 테스트 세트에서 확인합니다.

실험 결과에는 **실험 ID, 커밋, 데이터 버전 및 분할, 모델과 시작 가중치, 학습 설정과 시드, 판정 임계값, 실행 환경, 평가 결과, 실패 사례**를 남깁니다. 증류 실험에는 교사 모델과 가중치, 증류 대상 출력, 손실 가중치도 기록합니다.

모델, 데이터 설정, 평가 코드 변경은 기능 브랜치에서 진행합니다. PR에는 변경 이유, 재현에 필요한 설정 또는 명령, 기준 모델 대비 결과와 확인된 실패 사례를 포함합니다. 모델 출력 형식이나 판정 조건을 변경할 때는 시연 시스템의 연동 담당자와 적용 버전을 맞춥니다.
